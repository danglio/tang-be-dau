# 20/10 University Class Portal (47 Students) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a high-energy, beautiful, and personalized 20/10 web portal for 47 freshman university female students at `https://danglio.github.io/tang-lop/`, featuring instant search, dynamic 3D opening envelopes, personalized college letters, direct link sharing, and university-themed widgets.

**Architecture:** Single Page Application (SPA) in a dedicated standalone repository `tang-lop` with embedded JSON data of 47 students, Tailwind CSS (CDN), FontAwesome 6, Google Fonts, HTML5 Canvas particles, Web Audio API, and vanilla JavaScript URL parameter routing (`?id=N`).

**Tech Stack:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS, Canvas API, Web Audio API, Git, GitHub CLI, GitHub Pages.

## Global Constraints

- Standalone URL: `https://danglio.github.io/tang-lop/`.
- All 47 female students from the roster must be present with accurate full names and short names.
- Deep-linking support via query parameters (`?id=18` or `?name=...`) to auto-open designated envelope.
- Responsive mobile-first design for iPhone, Android, and Desktop.
- Autoplay background audio with passive gesture unlock on first tap.
